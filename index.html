LexIA: Local Multilingual RAG

ENSIAS end-of-year project · 2026

A private assistant that answers from your own documents, in French, Arabic or English, with cited sources. Nothing leaves your machine.

100% Top-5 retrievalRAGAS recall 0.91
Qwen 2.5 · bge-m3 · LlamaIndex · ChromaDB · FastAPI · Next.js · Docker
Case study
Problem
Sensitive documents can’t be sent to cloud LLMs, and generic chatbots invent answers.
What I built
A fully local pipeline: hybrid dense + BM25 retrieval, optional reranker, query rewriting, streaming answers, JWT/RBAC multi-user auth, and a strict “documents only” mode that refuses when the answer isn’t in the corpus.
Result
Evaluated on 30 questions: 100% Top-5 retrieval accuracy and RAGAS context recall of 0.91.

Secure Config & Audit Hub

ENSIAS DevSecOps project · Nov 2026

Three microservices secured with Zero Trust: no service trusts another by default, and every access decision is logged.

3 servicesAutomated 401/403 tests
Java 17 · Spring Security · Keycloak · OAuth2/OIDC · JWT · Docker · Maven
Case study
Problem
In many microservice setups, an internal service is trusted just because it sits behind the gateway.
What I built
Each service validates the JWT itself against Keycloak, with role-based access control. Inter-service calls use a service token. An audit log records allowed and denied access.
Result
Security behavior is verified by automated tests for both 401 (unauthenticated) and 403 (forbidden) cases.
